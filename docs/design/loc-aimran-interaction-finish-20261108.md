# LOC 互動視覺整理｜2026-11-08

## 方向與參考

參照 [AIMRAN Library](https://library.aimran.es/) 的互動元件語言；這是 UI 元件示例庫，而非 LOC 的資訊架構替代方案。取用的設計概念是 *spotlight card*、tactile pill、segmented navigation 與 restrained motion；沒有複製第三方元件程式碼、頁面內容、標誌或素材。

## LOC 的保留條件

- **首頁**：保留作者已編排的 Hero、標題、文字、作品內容與圖片；只補強框線、光感、卡片層次與互動回饋。
- **文化／統計／搜尋／痕跡**：保留原本的 SQL 載入階段、篩選、時間長河、圖表、搜尋、MapLibre 手勢、文章日期與雙色交替；視覺樣式共用，但功能不交叉替換。
- **主題**：沿用八組公開 Theme 的 `--loc-*` semantic tokens；日夜/主題切換與既有 Theme 管理、發布機制不變。
- **導航**：上方導航仍在正常頁面流，右側 LOC 返回按鈕、橫向捲動及 mobile touch target 不變。
- **編輯操作**：六個浮空操作鍵仍是獨立按鈕，儲存在左、取消在右；不加入容器攔截點擊。
- **無侵入性**：無新依賴、JS、資料呼叫、Schema、RPC、RLS、Gateway 或 auth 修改；樣式集中在 `app/styles/aimran-inspired.css`，最後由 `app/globals.css` 載入。

## 視覺範圍

| 介面 | 新的可見行為 |
| --- | --- |
| 首頁與四頁 Hero | 更有層次的細框、主題色光暈和深度陰影；既有 artwork 不覆蓋 |
| 頂部／功能導航 | 帶主題色的選取狀態、滑鼠／鍵盤焦點細緻反應 |
| 公開內容卡片與文章列表 | 聚光感、細微浮起、清晰 focus，保留條紋與順序 |
| 篩選、來源、分段選項 | 膠囊式選取對比與按壓回饋 |
| 六個浮空鍵 | 只做 hover／active 視覺，不改位置、排列或功能 |
| 載入狀態 | 在原文字旁顯示旋轉的主題色指示 |
| 動態偏好 | `prefers-reduced-motion` 停用浮動與旋轉；手機不依賴 hover |

## 視覺驗證

此次採使用者指定的 **直接 Merge → 上站目視** 流程，而非要求使用者做 code review。合併後查看首頁、文化、統計、搜尋、痕跡的桌面／手機顯示與八主題，重點是可見度、文字對比、圖表及地圖點擊、六鍵順序。靜態程式檢查不等於瀏覽器視覺驗收，也不等於已完成正式部署。
