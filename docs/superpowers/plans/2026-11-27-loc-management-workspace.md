# LOC 管理工作區整合

## 已完成基線

- 普通使用者的文化、痕跡、統計、搜尋四面向整合已由 PR #1973 合併。
- 搜尋 Pattern 建議、description 文章 UID 置頂、文章關係面板與痕跡地點到訪日期已包含在 main。
- 此工作從合併後 main 開新分支；LOC 不使用 Container，匯入責任留給 LAS。

## 目標與驗收

管理工作區以 vis-network、LOC 主題色與 Motion 呈現階層及功能切換；既有路由、資料所有權、授權、儲存／取消與未儲存變更保護維持有效。

1. 六鍵與管理入口順序符合作者指定；Group 管理入口改名為「群組管理」，路徑不變。
2. 系統管理不再提供人員架構；群組管理統合人員、群組及作品管理能力，伺服器端只接受 LOC 根群組管理授權或既有 global 授權。
3. 時間管理保留 vis-timeline 編輯器並補上時代／期間／定錨導覽圖；空間管理以痕跡→路徑→地點的圖譜減少多欄平面導覽。
4. 關鍵詞、文章、系統與群組工作區採一致的主題化圖譜導覽；保留可鍵盤操作的替代功能清單與 reduced-motion。
5. 首頁多區塊編輯以圖譜選取區塊、BlockNote 編輯目前區塊；既有單次交易儲存、預覽、取消及草稿保護不變。
6. 定向測試、完整 core tests、語法檢查、Cloudflare build/dry-run、Cloudflare Preview 與 Chrome 操作驗收均通過；確認沒有 Container binding 後才合併管理區 PR。

## 實作順序

1. 共享管理圖譜導覽元件及路由順序，先涵蓋 Group、Scope、文章與系統管理工作區。
2. 群組／人員功能歸位並落實根群組授權；移除系統管理內的重複人員入口。
3. 時間、空間、關鍵詞圖譜與首頁 BlockNote 區塊選取整合。
4. 回歸修正、完整驗證、Cloudflare Preview、Chrome 驗收，再建立並合併管理區 PR。

## 不在本次範圍

- LAS 匯入搬遷、SQL dialect portable、LOC Container、R2 移交。
- 四面向資料查詢的其他大規模資料流更動；PR #1973 已完成的查詢整合只做必要回歸。
