# Superpowers — 工程流程入口

- 先確定當前工作目標，再選需要的流程；不因啟動或每次工具呼叫而讀取所有技能。
- 有已安裝的 Superpowers Plugin 時，直接使用該 Plugin 的相關能力，**不要重新安裝或複製整套**。官方專案：https://github.com/obra/superpowers
- 規劃、偵錯、實作、測試、交付是不同情境，不是一條需要全部讀取的載入鏈。只有當前步驟需要時才讀它。
- 當前 LOC 專案以 `AGENTS.md` 與現行程式碼為準；Skill 不是自動授權改動其他模組。
- 如需過往專用技能原文，只在確認必要時查 `.agents/SKILL-LINKS.md` 的固定版本連結。
