# Web / App — 網頁與應用入口

以目前專案程式、Next.js、React、Capacitor/PWA 與 Extension 的實際運作為準。只有遇到特定 API、平台限制或瀏覽器檢測需求時才跟進相關專用指引。

UI 顏色、版面、交互設計優先改用 `ui-ux-pro-max`（不要兩份同時預載）；MCP Server 工作優先 `mcp-builder`。瀏覽器測試、Modern Web Guidance、Motion、React 最佳實務等小題目只作 `.agents/SKILL-LINKS.md` 連結，不做啟動必讀。

不用為新安裝 npm 模組再安裝同名 Skill；實作以前先查 LOC 真實版本與原有 code。
