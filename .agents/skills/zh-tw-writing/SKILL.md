# zh-tw-writing — 繁體中文顯示與說明文字

此技能是**對使用者顯示的繁體中文文字基本原則**。原始 [zh-tw-writing v1.2.0](guide.md) 聚焦正式文件；本 Repo 依使用者要求擴大觸發範圍，涵蓋平常解說、工程分析、Bug 診斷、測試報告、進度交付，以及 UI 上的標題、操作文案、提示與錯誤訊息。**原文中「一般對話不適用」的限制，在本專案由此入口取代**；其餘細節按需參考原文。

- 自然、準確、符合台灣習慣的繁體中文，保持技術名詞、專有名稱和中英文混排一致。
- 以完整語意串接前因後果，不把一句事情切成數段碎句，不用空泛 AI 套話、翻譯腔、制式口號或不必要的粗體標籤；真正有比較、流程或資訊密度需求時可用清單與表格。
- 事實、推測、已驗證、未驗證分清楚；潤稿不添加原文沒有的內容，不改數字、日期、引用、狀態或責任歸屬。
- 適度變化句型，標點以閱讀清晰為準，不拿報告的逗號比例硬套短答、UI 或操作步驟。
- 文字風格不覆蓋本 Repo 專業判斷或使用者已指定的創作／作品用語；不自動改動程式碼、Commit 訊息、外部原文引述及系統契約。

**載入方式**：基本對話與 UI 文字只需要本檔；正式長文、英翻中、詞語選擇才按需讀取 [guide.md](guide.md) 及 `references/` 個別檔案。對有必要校對的本地 Markdown、HTML、文字檔，才執行 `python3 .agents/skills/zh-tw-writing/scripts/check_zh.py <檔案>`，並依實際語境判斷提示；無須每次對話跑腳本。保留既有其他專業 Skills，不把它們的規則重複安裝到此處。
